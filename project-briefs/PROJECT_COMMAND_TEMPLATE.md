# Project Command Template

Using the Portfolio Agent Factory rules in AGENTS.md, create a [PROJECT TYPE] for [INDUSTRY / USER TYPE].

Requirements:

- Make it distinct and portfolio-worthy.
- Use a unique sub-brand for this project.
- Include subtle Volatile | Solutions attribution.
- Create a detailed README.
- Score the project before publishing.
- Only publish if the final score is 85 or higher.
- Create a public GitHub repo.
- Prepare it for Netlify deployment.
- Return the GitHub URL, Netlify URL if deployed, project score, and any limitations.
